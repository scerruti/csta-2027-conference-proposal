# CSTA 2027 Proposal Rubric Score Report

## Scope

This report records the scores of record from a blind review, following the [blind scoring procedure](Scoring-Instructions.md#blind-scoring-required-before-each-report). One reviewer scored both proposals in a single session, using the same counting rules for both. The reviewer had only the [rubric tiers](Rubric-Tiers.md), each proposal's Markdown file, and each proposal's Presentation Outline PDF.

- [AP Score Reports as Instructional Data](../../projects/ap-score-reports/proposals/ap-score-reports-as-instructional-data/AP-Score-Reports-as-Instructional-Data.md): Session (1 hour).
- [AP Scores to Instructional Action: A Quick Workflow](../../projects/ap-score-reports/proposals/ap-score-reports-quick-workflow/AP-Score-Reports-Quick-Workflow.md): Mini-Session (20 minutes).

Reviewer: a fresh subagent, model opus, one session for both proposals. Review date: 2026-10-18. This is round four.

## Compliance

Both proposals pass the submission check (`tools/validation/check_submission.py`) on every automated item. Manual items remain: the website form fields and the outline PDF upload.

## Review: AP Score Reports as Instructional Data

| Criterion | Score | Evidence and gaps |
|---|---:|---|
| CSTA Standards | 4/5 | 4g tied to Steps 2, 4, and 6. 4f tied to Step 4 and Step 6. 5f tied to Step 7. No student subtopics. The reviewer found the 5f link weak, since teachers build the assessment but do not guide students' use of feedback. |
| Content | 4/5 | Template used, and the PDF matches the proposal. The 0:11–0:31 block asks for individual exports, imports, benchmark comparison, cell circling, a regroup, dependency checks, and two discussions in 20 minutes, which the reviewer doubted is achievable. |
| Educational Best Practices / Pedagogy | 5/5 | Three distinct practices, each grounded: Data Wise, formative assessment (Black and Wiliam, 1998), and concept-level diagnosis (Cabo, 2015). The reviewer noted that formative assessment overlaps Data Wise Step 7. If it is folded into Data Wise, the count is two and the score is 4. |
| Engaging and Relevance | 4/5 | Works with each participant's own report data, which is relevant. The audience is narrow, and Data Wise is an established method rather than a new one. The grade level is implied, not stated. |
| Takeaways | 4/5 | Tangible and intangible takeaways are named. The Participant Resources section was missing from the version scored in this round and has since been restored. One intangible takeaway. |
| Attendee Preparedness | 4/5 | Attendees draft an action plan and build a formative assessment from the question bank. Participants without data act as supporters, and the tight Step 4 may leave some plans unfinished. |
| Overall Recommendation | 4/5 | Recommend (top 25%). |

### Final Score: 29/35

### Improvements

- Reconsider the 5f link, or describe how the formative assessment gives students feedback
- Reduce or reorganize the Step 4 block
- Re-check the restored Participant Resources section in a fresh review, since this round did not see it
- State the grade level
- Decide whether formative assessment is a separate practice (keep it) or part of Data Wise

## Open Verification

- **Cabo (2015):** the citation supports a concept-level claim. The claim comes from a search summary of the paper, and the paper itself has not been read. Read the paper and confirm the claim before the proposals are submitted or pushed.
- **Black and Wiliam (1998):** the citation is verified from the journal record. The effect-size figure from a low-quality source is not used.
