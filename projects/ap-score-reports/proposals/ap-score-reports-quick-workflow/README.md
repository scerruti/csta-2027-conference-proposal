# AP Scores to Instructional Action: A Quick Workflow

## Purpose

The 20-minute mini-session. It is the "why": why averages and pass rates can hide causes, and how the Data Wise process works as a map. Attendees leave with a take-home guide to start the process with their own data.

## Relationship to the Breakout

The breakout gives the guided, hands-on "how" for the same process. This session is designed to run before it, but it stands alone.
